# Install PAN OS in VMWARE

## Install VMWARE

## Setup Virtual Network

Add VMNET 0  Bridge

Add VMNET 1 Host-only 10.1.1.0

Add VMNET 2 Host-only 10.2.2.0

Add VMNET 3 Host-only 10.3.3.0

Add VMNET 4 Host-only 10.4.4.0

Add VMNET 5 Host-only 10.5.5.0

Add VMNET 6 Host-only 10.6.6.0

Add VMNET 7 Host-only 10.7.7.0

Add VMNET 8 NAT 	  192.168.246.0

## Import PAN OS 10.0.0 to VMWARE

Setup RAM 8Gb

Add Network interface 4, 5, 6, 7

Setup :

Network Adapter 	NAT

Network Adapter2 	Bridge

Network Adapter3	Vmnet1

Network Adapter4	Vmnet2

Network Adapter5	Vmnet3

Network Adapter6	Vmnet4

Network Adapter7	Vmnet5

Network Adapter8	Vmnet6

## Notes:

- Go to VMWARE VM Panos folder, Open .vmx file with notepad
- Check to see if ethernet0.virtualDev = "vmxnet3" then use vmxnet3 for other virtualDev interface too
- after start the firewall, you need to wait for 10 minutes for all firewall services start then you can change the password.
- Login user is admin
