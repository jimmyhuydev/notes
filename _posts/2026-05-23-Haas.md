# HAAS Machine startup inspection Checklist

- Machine main breaker is in the on position

- Air pressure gage reads between 85-115 psi

- Coolant screen on the coolant tank is free of chips (clean if chips are found)

- Coolant level filled to the bottom of the coolant screen

- Interior of the machine is free of chip(clean if chips are found)

- Start the machine at the panel

- Home the Machine

- Run Warm up program
